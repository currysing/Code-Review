CriticalF-01: Committed credentials or key material

Plain-English explanation. the project contains passwords, client secrets, access keys, private-key material, or certificate passwords in files that are part of the repository. Source-controlled secrets are not private. Anyone with a clone, backup, CI artifact, or leaked archive can read them. Even if a value is intended for development, teams often reuse it or accidentally deploy it.

Recommended fix. Rotate affected secrets, remove them from source control, and load values from environment variables, deployment secrets, or a vault. Add secret scanning to CI.

MediumF-02: Swagger/OpenAPI appears enabled in committed configuration or runtime code

Plain-English explanation. Swagger publishes a browsable list of API endpoints and request/response schemas. That is useful for developers, but in production it helps attackers discover hidden or sensitive routes quickly, especially when some endpoints are weakly protected.

How it surfaces in this project. The evidence below shows the concrete files and lines where this pattern appears.

  • intf-iamint/DPOCorpID.Core/appsettings.Development.json:36 "OpenSwagger": true, // Enable Swagger UI
  • intf-iamint/DPOCorpID.Core/appsettings.Production.json:37 "OpenSwagger": true, // Enable Swagger UI
  • intf-iamint/DPOCorpID.Core/appsettings.DciDevelopment.json:36 "OpenSwagger": true, // Enable Swagger UI
  • intf-iamint/DPOCorpID.Core/appsettings.json:33 "OpenSwagger": true, // Enable Swagger UI

Why it matters. Public API documentation can expose sensitive endpoint and model details, especially when combined with weak auth.

Recommended fix. Disable Swagger in production or protect it with admin authentication and network restrictions.

Limitations

This was a first-pass static review. I did not run the service, verify deployed ingress controls, exercise endpoints, review every business rule, or perform dependency/CVE analysis. External gateway controls may reduce exposure but do not remove risks from committed secrets, disabled validation, or debug code in deployable projects.
